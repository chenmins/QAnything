# 构建版本对比

## 版本概览

| 项目 | 完整版本 | Bots分享版本 |
|------|---------|-------------|
| **构建命令** | `pnpm build` | `pnpm build:bots` |
| **输出目录** | `dist/qanything` | `dist/bots-only` |
| **部署场景** | 内部管理系统 | 公网分享服务 |
| **访问权限** | 需要权限控制 | 公开访问 |

## 功能模块对比

### 路由对比

| 路由路径 | 功能说明 | 完整版本 | 分享版本 |

| `/bots` | 机器人管理列表 | ✅ | ❌ |

| `/bots/:id/share` | 分享页面 | ✅ | ✅ |
| `/quickstart` | 快速开始 | ✅ | ❌ |
| `/statistics` | 统计页面 | ✅ | ❌ |

|---------|---------|---------|

## 使用场景

### 完整版本使用场景

```
管理员 → 登录后台 → 创建机器人 → 配置知识库 → 发布分享
```

**部署建议：**
- 部署到内网或有访问控制的服务器
- 域名示例：`https://admin.example.com/qanything/`
- 需要配置登录认证

### 分享版本使用场景

```
用户 → 访问分享链接 → 直接与机器人对话
```

**部署建议：**
- 可以部署到公网
- 域名示例：`https://chat.example.com/` 或 `https://bot.example.com/`
- 无需登录，直接访问

## 安全性对比

| 安全特性 | 完整版本 | 分享版本 |
|---------|---------|---------|
| 包含管理代码 | ✅ 是 | ❌ 否 |
| 需要访问控制 | ✅ 必须 | ⚠️ 建议API层控制 |
| 可以创建机器人 | ✅ 是 | ❌ 否 |
| 可以编辑配置 | ✅ 是 | ❌ 否 |
| 防止路径遍历 | ⚠️ 需服务端控制 | ✅ 构建时隔离 |

## 构建产物大小对比（预估）

| 版本 | 预估大小 | 说明 |
|-----|---------|------|
| 完整版本 | ~2-3 MB | 包含所有功能模块 |
| 分享版本 | ~800 KB - 1.5 MB | 仅包含分享相关代码 |

**注意：** 实际大小取决于依赖和构建优化配置

## 配置文件对比

### 完整版本配置
```env
# .env.production
VITE_APP_API_HOST=/api
VITE_APP_API_PREFIX=/api
VITE_APP_WEB_PREFIX=/qanything
VITE_APP_MODE=prod
```

### 分享版本配置
```env
# .env.production.bots
VITE_APP_API_HOST=/api
VITE_APP_API_PREFIX=/api
VITE_APP_WEB_PREFIX=/qanything
VITE_APP_MODE=bots-only  # 关键区别
```

## 开发建议

1. **本地开发**：使用完整版本（`pnpm dev`）
2. **功能测试**：在完整版本中测试所有功能
3. **分享测试**：切换到 bots-only 模式测试分享功能
4. **生产部署**：根据需求分别构建和部署两个版本

## 扩展建议

如果未来需要更多版本，可以参考相同模式：
- `build:knowledge` - 仅知识库管理版本
- `build:quickstart` - 仅快速开始版本
- `build:minimal` - 最小化版本

每个版本都应该：
1. 有独立的 `.env.production.xxx` 配置
2. 有独立的 `routes.xxx.ts` 路由文件
3. 有独立的构建脚本
4. 有独立的输出目录
